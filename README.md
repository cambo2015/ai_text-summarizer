

# Alpha Grape
Alpha Grape is a meeting summarizer with ChatGPT and Mistral LLM integration.
It will summarize audio from an audio file. 

# Running the application
To get this running see the respective README.md files in /backend and /frontend

## Docker Setup
For docker setup see the readme in /backend

## Local Setup (Non-Docker)
### Dependencies
* Chat GPT and Mistral API keys
* Ffmpeg (install from command line)
* Python
* MySQL
* Stripe tiered setup
* IntelliJ - used to run the application
